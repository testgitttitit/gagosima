# 변경 내역

## 2026-10-28 — 길찾기 다시 수정
- 앱 링크(nmap://) 제거 → PC·휴대폰 모두 네이버 지도 웹 길찾기(휴대폰은 네이버 모바일 '빠른길찾기'로 열림).
- '경로'·'도보' 버튼: '내 위치'를 안 켜도 누를 때 위치를 받아 출발지로 넣고 같은 탭에서 엶.
- '오늘 경로': 숙소 → … → 숙소로 출발·도착이 같아 경로가 안 나오던 문제 → 마지막 숙소를 빼고, 하루 동선은 자동차 경로로(경유지는 하루 전체에서 고르게 5곳).
- 1.2km 미만 구간은 도보 길찾기.

## 2026-10-28 — PC에서 길찾기 버튼이 안 열리던 문제
- 길찾기 버튼이 네이버 지도 앱 링크(nmap://)만 써서 PC·앱 없는 폰에선 반응이 없었음 → PC는 네이버 지도 웹 길찾기, 휴대폰은 앱을 열고 1.5초 안에 안 열리면 웹으로.
- 네이버 폴더 장소는 장소 ID를 같이 넘겨 정확한 가게로 잡힘. 엑셀 길찾기 링크도 웹 주소로 변경.
