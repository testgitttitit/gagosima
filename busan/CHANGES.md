# 변경 내역

## 2026-10-28 — PC에서 길찾기 버튼이 안 열리던 문제
- 길찾기 버튼이 네이버 지도 앱 링크(nmap://)만 써서 PC·앱 없는 폰에선 반응이 없었음 → PC는 네이버 지도 웹 길찾기, 휴대폰은 앱을 열고 1.5초 안에 안 열리면 웹으로.
- 네이버 폴더 장소는 장소 ID를 같이 넘겨 정확한 가게로 잡힘. 엑셀 길찾기 링크도 웹 주소로 변경.
